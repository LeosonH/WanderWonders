## Commands

```bash
npm run wonder:local-check
npm run wonder:local-start
npm run wonder:local-reset-twice
npm run wonder:local-stop
```

Both scripts fail fast when Docker or the CLI is unavailable and refuse to operate if a Supabase link marker is present. They use `--local` explicitly. On this Mac the Docker CLI is installed inside Docker Desktop but is not on the default `PATH`; the scripts use that fixed app-bundled path when needed. The ports are isolated from the other local Supabase stack already running on the default range.

## Step 4 verification

The CLI-generated migrations are:

- `20260802063506_wonder_domain_functions.sql`: empty-search-path private helpers, snapshots, authenticated RPCs, and the service-only verified-start RPC.
- `20260802064501_wonder_role_timeouts.sql`: five-second `authenticated`/`service_role` role statement budgets plus the PostgREST config reload notification.

The public function grants are explicitly allowlisted. State-changing RPCs use the per-user advisory lock, profile row lock, expected `state_revision`, UUID idempotency, typed envelopes/errors, and a two-second function-local `lock_timeout`. UI telemetry is the sole gameplay-lock/revision exception and is capped at 200 owner/UTC-day rows. Online offers are weighted server selection; offline sync validates the versioned SHA-256 slug order and stores accepted or `WW_DAILY_FLOWER_CAP`/`rejected_tier` results.

Final local evidence:

```bash
SUPABASE_TELEMETRY_DISABLED=1 npx supabase test db --local
SUPABASE_TELEMETRY_DISABLED=1 npx supabase db lint --local --fail-on error
Scripts/verify_wonder_concurrency.sh
Scripts/verify_wonder_role_timeouts.sh
```

The schema and RPC suites passed 59/59 pgTAP assertions. Lint reported no schema errors. The concurrency probe proved one same-user mutation plus one stale-revision result, exactly one Glow ledger entry, and the two-second lock timeout. The PostgREST probe measured authenticated at 5.026 seconds and service role at 5.009 seconds for the disposable six-second call; normal refresh and service-only verified start completed below one second. The disposable timeout helper was removed after the probe.
